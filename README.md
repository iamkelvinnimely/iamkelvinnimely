# 🚀 Things I've Built

## 🌐 PN Gateway

**Cloud management platform for WISPs and hotspot operators.**

PN Gateway helps network operators manage routers, customers, hotspot services and network operations from a centralized platform.

**Built with:**

`Django` `React/Vite` `PostgreSQL` `Redis` `Celery` `Docker` `AWS`

---

## 🎓 EdCarry

**School Management SaaS for schools.**

EdCarry is designed to help schools manage their academic and administrative operations digitally.

The platform focuses on bringing school management processes into one centralized system.

**Built with:**

`Django` `Django REST Framework` `NextJS` `PostgreSQL` `Redis` `Celery` `AWS` `S3`

---

## 📚 CodeDator

**A learning platform built for digital education.**

CodeDator is focused on creating a better environment for learning technology and programming online.

**Built with:**

`Next.js` `Node.js` `Express` `MongoDB`

---

## 🐄 GM Range Farm Management System

**Digital management system for livestock and poultry operations.**

Designed to help farms manage:

* 🐄 Livestock
* 🐔 Poultry
* 🌾 Feeding
* 💊 Animal health
* 📦 Inventory
* 💰 Finances
* 🥚 Egg production
* 📊 Farm analytics

The goal is simple:

> **Turn farm operations and records into useful data.**
